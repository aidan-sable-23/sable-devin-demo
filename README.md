# Devin demo app

A tiny Flask task-tracker API, built only as a sandbox for a live Sable product demo of
Cognition's Devin. Not a real product.

## Run it

    pip install -r requirements.txt
    python app.py

## Run the tests

    pytest

There's a feature noted as a TODO in `app.py`: marking a task done and deleting a task
aren't implemented yet.
